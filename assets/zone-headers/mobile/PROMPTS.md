# Mobile zone header generation notes

## Output specification

- Final size: 768 x 880 pixels (7:8 portrait)
- Format: optimized RGB PNG
- Reference 1: the matching desktop header in `../environment-focused/`
- Reference 2: `11-voidiron-abyss-v5.png`, used only for mobile framing and the approved smooth finish
- Composition: close-to-ground viewpoint; terrain occupies roughly the lower 40%; a path, ledge, shoreline, or opening leads into a broad vista; buildings remain sparse and secondary; central areas stay readable beneath translucent UI
- Rendering: polished high-fantasy digital matte painting, broad shapes, smooth atmospheric transitions, coherent matte materials, controlled selective detail, restrained highlights
- Exclusions: characters, UI, borders, crests, text, logos, watermarks, blank margins, grain, speckles, glitter, dust motes, excessive micro-detail, crunchy sharpening, repeated buildings, busy distant architecture, and smooth empty foregrounds
