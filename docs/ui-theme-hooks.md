# Calculator theme hooks

The working calculator now names its layout containers and frames with a
`data-ui` attribute. This covers `index.html`, the Construction & Village
Planner renderer, and the shared item/gear sprite renderer. It includes
static markup, HTML generated by JavaScript, and containers built with
`document.createElement()`.

The historical `index2.html` and `IdleWorlds_Toolkit_v4_8.html` builds and the
separate `Skillsim` developer tool are outside the working calculator.

## Naming convention

- Names are stable, lowercase, hyphenated CSS hooks, such as `panel-results`,
  `result-hero-divider`, `gn-plate-frame`, and `cv-building-panel`.
- Existing IDs provide the name where available. Shared components generally
  use their existing component class. Anonymous wrappers use their purpose
  and surrounding component, such as `village-slot-controls`.
- Repeated components intentionally share a name. Scope them under a named
  section or use existing row/slot attributes to select a particular instance.
- Existing IDs, classes, accessibility attributes, and form names retain their
  roles. `data-ui` is the dedicated theme hook; it is not an HTML form `name`
  or an accessibility label.
- Source markup uses valid unquoted attribute values (`data-ui=panel-results`)
  so the same convention works inside single-quoted, double-quoted, and
  template-literal JavaScript strings. Browser DevTools displays the usual
  quoted HTML representation. CSS selectors should quote the value.

## Styling examples

```css
/* Shared panel interiors across the calculator. */
[data-ui="panel-body"] {
  background: var(--surface);
  border-radius: 12px;
}

/* A particular section's version of the shared component. */
[data-ui="tab-calculator"] [data-ui="panel-head"] {
  border-bottom: 1px solid var(--border);
}

/* An individual decorative frame. */
[data-ui="gn-plate-frame"] {
  border-color: var(--accent);
}

/* A repeated component scoped to one of the five construction plots. */
[data-ui="cv-scene"] [data-ui="cv-plot"].cv-plot-0 {
  filter: drop-shadow(0 4px 6px #0006);
}
```

These examples are selector patterns, not an installed theme. Scope your new
theme's rules under its root selector when integrating it. Existing inline
styles still participate in the cascade: prefer changing the existing theme
variables, and use targeted overrides where necessary. Sprite background
coordinates are managed by the icon loader and should be preserved when
restyling their surrounding frames.

## Finding every name and maintaining coverage

Search the source for `data-ui=` or inspect the element in browser DevTools.
The source audit produces an exhaustive JSON inventory with each name, tag,
file, and line:

```sh
python tools/audit_ui_names.py
python tools/audit_ui_names.py --inventory
python tools/audit_ui_names.py --self-test
node tools/check-inline-scripts.js index.html
```

Give new containers a name directly in their template. For DOM-created
containers, set `element.dataset.ui = 'component-name'` immediately after
creation. Keep names independent of selection state, item names, array
indices, and rendering order. The profile skill tile assembles its opening
tag dynamically and shares `data-ui=cp-skill` across its button/div variants.

The source audit covers literal templates and direct `createElement()` calls
in the three UI files. It is not a JavaScript interpreter; check dynamically
composed markup and new interactive states in a browser too. A read-only
DevTools check for unnamed layout containers is:

```js
const containers = 'body,main,div,section,article,aside,header,footer,nav,form,' +
  'fieldset,details,summary,dialog,table,thead,tbody,tfoot,tr,th,td,ul,ol,li,' +
  'dl,dt,dd,figure,figcaption,span,iframe,frame,frameset,canvas';
[...document.querySelectorAll(containers)]
  .filter(element => !element.getAttribute('data-ui'));
```

Controls, text elements, and SVG internals continue to use their existing
IDs, classes, attributes, and normal element selectors. The naming pass adds
theme hooks without changing the existing appearance or calculator logic.
