Audit rules and verified winning methods
Model boundary. This remains an independent-skill simulation: no personal gear selection, potions, race, daily/server bonuses, temporary buffs, banked materials, market purchases or Work Orders. The three controls above are deliberate global simulation inputs. Known recipe inputs are produced from scratch. Cross-skill production adds elapsed time but does not add XP to the skill being simulated; same-skill producer actions add both time and their effective XP. Supplier-skill training time is not added: when a T18 recipe needs Kingssteel Ore, the time to obtain that ore is charged, but a second Mining 1→69 journey is not nested inside the target skill.

Developer balance fields: each skill row has its own Base XP balance percentage. This modifies that skill’s underlying action XP before Gather %, flat EXP/action and Housing are evaluated. 0% = unchanged, +100% = 2.00× base XP, +200% = 3.00× base XP. The multiplier applies to every XP-producing action belonging to that skill, including same-skill producer chains such as Smelt → Smithing craft, Weave → Tailoring craft and Harvest Mana → Spellcrafting craft. Cross-skill input production time is still charged without granting XP to the target skill.

Global modifier formulas copied from the Toolkit Calculator: Gather % is a bonus above the base 100% resource yield, so expected yield is (100 + Gather%) / 100. Gather actions earn XP for the expected number of resources, while flat EXP/action is added once per action. Housing uses effectiveDuration(); for actions over 10s it subtracts round((baseSeconds / 10) × housingTier), with a 5s floor. Flat EXP/action uses the Toolkit duration factor max(1, round(effectiveDuration / 10)).

Jewelcrafting rule requested for this simulator: Prospecting only. Cut Gems, Rings and Amulets are not candidates. Each Prospect consumes 2 ore, so its self-sufficient cycle is 20s mining + 10s prospecting = 30s.

Verified winners through the Level-70 range (T1–T18):
⚔️ Combat — normal-zone deterministic baseline, highest unlocked tier. Live Zone Control is faster as of patch .561, but its capture/lockdown uptime is dynamic, so an exact fixed 1→70 time is not claimed here.
⛏️ Mining — highest unlocked ore.
🌿 Gathering — highest unlocked herb/fibre; both use the same base curve.
🧪 Alchemy — any potion; all three potion types tie.
🔨 Smithing — T1 Reinforcement Plate; T2–T18 Chest.
🧵 Tailoring — T1–T18 Robe. Cloaks/Thread upgrades are excluded because their Silkbind/Orb acquisition cannot be fully deterministic from public base data.
💎 Jewelcrafting — Prospecting only, T1–T18.
✨ Spellcrafting — Harvest Mana, T1–T18. Enchants and Lesser Caches were fully costed and independently lose at every tier; regular Arcane Caches require an Upgrade Orb and are excluded.

Two deliberate exclusions: the live +20% Spellcrafting catch-up bonus at level 70 or below is not applied because this simulator is explicitly raw-base XP; and Zone Control is not used for Combat because its current 3×-base hit XP has non-deterministic capture/lockdown uptime and is outside the Toolkit Planner route model.

Route accounting: XP overflow from the final completed action/closed craft loop in one bracket is carried into the next bracket. The simulator re-evaluates every candidate after each modifier change, so Gather %, EXP/action or Housing can legitimately change which action is optimal.
